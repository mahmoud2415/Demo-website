# Mahmoud Restaurant Demo

A full, Arabic-first restaurant ordering showcase. It uses fictional content to demonstrate a reusable ordering experience for prospective restaurant clients.

## Status

Planning and documentation are complete; implementation has not started.

## Documentation

- [Project brief](docs/project-brief.md)
- [Technical architecture](docs/technical-architecture.md)
- [Scope and roadmap](docs/scope-and-roadmap.md)
- [Firebase launch guide](docs/firebase-launch-guide.md)

## Intended Stack

React + TypeScript, Firebase Hosting, Firestore, Firebase Authentication, Cloudinary, and WhatsApp click-to-chat.

## Local Development

```sh
npm install
npm run dev
```

Create a production build with `npm run build`. The demo works with its fictional local menu until Firebase credentials and Firestore integration are connected.
